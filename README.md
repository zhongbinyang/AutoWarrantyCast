> **AutoWarrantyCast** 是面向汽车主机厂（OEM）的专业级**车辆保修成本精算与预测系统 (Vehicle Warranty Cost Actuarial & Reserve Forecasting System)**。
> 基于双变量（时间+里程）竞争风险威布尔寿命分布模型、小样本冷启动经验贝叶斯正则化、Bornhuetter-Ferguson 索赔精算三角填充与蒙特卡洛随机模拟，精准预测剩余保修期内的索赔台次、索赔金额、单台保修费用（CPU）与财务责任准备金。

## 🚀 独立版运行（直接发给他人，无需 Python 环境）

1. 安装 Python 3.10+ 并确保已加入系统 PATH。

## 数据格式规范

### 1. 月度销量文件
CSV 或 Excel，两列：`销售月份`（`YYYY-MM`）、`销量`（整数）。

### 2. 索赔三角形文件（台次/金额通用）
Excel，单个 Sheet：
- 行：`销售月份`（与销量表对应）
- 列：发展期 `MIS0, MIS1, MIS2, ...`（车龄，月），数值为该发展期的**增量**索赔金额或台次
- 系统会自动检测并转换**累积口径**为增量口径（基于行内非递减比例的启发式判断），并在界面提示
- 数据截止日期（"as of" 月份）由每行最后一个非空发展期自动推断（取所有批次中的最大值）；超出截止日期的单元格应留空（`NaN`），代表尚未发生、待预测

### 3. 月均行驶里程文件（可选）
CSV，两列：`销售月份`（`YYYY-MM`）、`月均行驶里程`（公里/月）。不提供时，威布尔模型自动退化为纯时间模型。

## 模型原理

### 1. 双变量（时间+里程）竞争风险威布尔模型

生存函数：

```
S(t, m) = exp[ -(t/η_t)^β_t - (m/η_m)^β_m ]
```

累积故障率 `F(t, m) = 1 - S(t, m)`。时间与里程两个失效机制视为竞争风险，其累积风险（hazard）直接相加。

- **分段威布尔（时间维度）**：允许 `β_t` 按用户指定或自动检测的分段点分段独立取值，同时通过"锚定延续"的方式保证累积风险函数 `H_t(t)` 在分段点处连续 —— 每一段的局部尺度参数由锚定在上一段末端风险值之上的加权对数-对数线性回归求得。里程维度 `η_m, β_m` 采用单段拟合。
- **自适应分段**：对销量加权的池化累积风险曲线做二阶差分，取曲率变化最大的若干点作为候选分段点（`weibull_model.auto_select_breakpoints`）。
- **联合精化**：以分段回归结果为初值，使用 `scipy.optimize.least_squares` 对全部参数（分段 `β_t, η_t` + `β_m, η_m`）在所有（批次, 车龄）观测点上做加权非线性最小二乘联合拟合，权重为该批次销量（暴露量），使里程效应与时间效应的耦合（同一车龄下不同批次因月均里程不同而对应不同累积里程）被正确建模。
- **拟合优度**：报告 R² 与 MAPE（预测累积故障率 vs 实际累积故障率）。
- **贝叶斯威布尔（可选，需 PyMC）**：以 MLE 估计值为先验中心（LogNormal 先验），用 NUTS 采样器获得后验分布；下游蒙特卡洛模拟直接复用后验样本协方差矩阵（而非渐近正态近似），更真实地反映参数不确定性。PyMC 未安装时自动回退为 MLE 方法。

由于原始数据是**三角形聚合数据**而非个体失效时间，模型在**批次累积故障率曲线**（`该批累计索赔台次 / 该批销量`，销量加权）上拟合，而非逐车最大似然。

### 2. 台次预测与"锚定校准"

对每个销售批次，未来累积台次 = 威布尔模型预测的累积故障率 × 销量 + 校准偏移量；校准偏移量 = 该批**最后一个实际观测车龄**处的真实累积台次 − 模型在同一车龄的预测值。这保证预测曲线从历史实际值处平滑衔接，而不是跳变到模型的无条件曲线。未来增量 = 相邻车龄累积台次之差（并做非递减修正）。

### 3. 单次维修成本预测

```
单次维修成本(车龄) = 该车龄总索赔金额 / 该车龄总索赔台次
```

支持四种预测方法（`cost_model.py`）：

| 方法 | 说明 |
| --- | --- |
| 历史均值法 | 销量（索赔台次）加权的历史单次成本均值，作为未来所有车龄的平预测值；默认推荐，简单稳健 |
| 移动平均法 | 滑动窗口（默认 3 期）均值外推 |
| 指数平滑法 | Holt 线性（水平+趋势）双参数指数平滑，外推 `level + trend × horizon` |
| XGBoost 回归 | 以车龄、车龄² 为特征训练梯度提升树；未安装 `xgboost` 时自动回退为 `sklearn.GradientBoostingRegressor` |

预测区间通过**残差自助法（Bootstrap）**获得：从历史拟合残差中有放回抽样，叠加到点预测上，用于蒙特卡洛模拟。

### 4. 索赔金额预测（三选一）

1. **台次×单次成本法（默认/重点强调）**：`预测金额 = 预测台次 × 预测单次维修成本`。蒙特卡洛模拟时，每次迭代**同时**从台次分布与单次成本分布抽样后相乘，保证两者相关性被正确保留。
2. **链梯法（Chain Ladder）**：经典发展因子法，基于历史（批次, 相邻车龄）观测对的销量加权发展因子逐期外推。**已知局限**：对完全超出历史观测窗口（所有批次均未观测到）的车龄，发展因子默认取 1.0（即假设无进一步发展），这是保守简化，如需更精细的尾部外推建议使用台次×单次成本法。
3. **LightGBM 发展因子法**：以（车龄、对数累积值）为特征训练 LightGBM 回归发展因子，替代链梯法的固定因子假设；未安装 `lightgbm` 或训练样本不足（<8 对）时自动回退为链梯法。

### 5. 在保车辆数（暴露量）

第 j 月末仍在保 = 销量，当且仅当同时满足：
- 时间：`j ≤ 保修期月数`
- 里程（若设置里程限制）：`月均行驶里程 × j ≤ 保修期里程限制`

两者取更早失效的一方（"先到为准"）。

### 6. 蒙特卡洛模拟

对威布尔参数（从拟合协方差矩阵或贝叶斯后验采样）与单次成本残差（自助法）联合采样 N 次（默认 5000），每次迭代计算未来总台次与总金额，得到经验分布，进而给出：

- 均值、标准差、变异系数（CV）
- VaR90 / VaR95（本系统采用"结果分布的第 90/95 百分位数"这一实务口径，而非相对均值的损失定义）
- 若上传真实未来数据，额外计算 MAE、MAPE

模拟核心实现完全向量化（NumPy 广播，按批次循环、按模拟次数向量化），5000 次模拟通常在数秒内完成，无需额外的进程级并行。

### 7. 关键指标定义

| 指标 | 定义 |
| --- | --- |
| 批次累积故障率 | 该批保修期内预测总台次 / 该批销量 |
| 批次单台费用 | 该批保修期内预测总金额 / 该批销量 |
| 月度平均故障率（车龄 j） | 所有批次在车龄 j 的预测台次之和 / 车龄 j 在保车辆总数 |
| 月度单次维修成本（车龄 j） | 所有批次在车龄 j 的预测金额之和 / 预测台次之和 |
| 月度单台费用（车龄 j） | 所有批次在车龄 j 的预测金额之和 / 车龄 j 在保车辆总数 |

## 界面使用步骤

1. **数据导入区**：上传月度销量 → 选择单系统/多系统导入模式 → 上传对应索赔台次/金额三角形 → 查看校验提示与热力图预览。
2. 在侧边栏设置保修期、里程参数、预测方法、分段方式、蒙特卡洛次数。
3. 点击「🚀 运行预测模型」。
4. **预测结果展示区**：按系统查看三角形（预测值浅黄色底色高亮）、故障率曲线（含 90% 置信带）、单次成本趋势、批次汇总、跨批次月度汇总、预测可信度报告（含可选验证数据上传）。
5. **下载区**：按系统下载四 Sheet（台次/金额/单台费用/故障率）Excel（保留高亮），或下载批次汇总 CSV。
