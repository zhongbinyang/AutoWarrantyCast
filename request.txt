
你是一名资深数据科学工程师，需为主机厂保修成本工程师开发一套**车辆保修成本精算与预测系统**。系统基于每月新车销量、已发生的分系统索赔金额与台次三角形数据，预测剩余保修期内各月索赔台次与金额，并输出单台费用、故障率、可信度等指标。Streamlit 界面必须满足特定的数据导入与输出格式要求，支持**保修期时间+里程双维度设定**、**月均行驶里程输入**，并直观展示**故障率曲线与预测可信度**，同时为每一销售批次输出**质保期内累积故障率与单台费用**。

## 一、用户角色与核心需求
- 用户：主机厂保修成本工程师
- 业务背景：已知每月新车销量，各销售月份车辆在售后不同月份已发生的索赔金额与台次。需预测未来剩余保修期内（以先到的时间或里程为准）每批车辆的月度索赔台次与金额，并汇总关键成本指标。
- 核心功能要求：
  1. **数据导入**：按三个区域分别导入“月度销量”、“索赔台次”、“索赔金额”。支持单系统与多系统模式（9大系统独立上传）。
  2. **保修期与行驶里程参数输入**：
     - 保修期时间（月数，默认36）
     - 保修期里程（公里，选填）
     - **每月行驶里程**：固定值或上传文件（按销售月份），用于里程相关故障建模。
  3. **预测输出**：
     - 填充剩余保修月份的预测台次和金额，**预测值单元格标注浅黄色底色**。
     - 汇总各系统**月度平均故障率**、**月度单次维修成本**、**月度单台费用**。
     - **按销售月份（批次）**输出质保期内的**累积故障率**（总故障台次/销量）和**单台费用**（总金额/销量），并用趋势图展示。
     - 绘制**故障率曲线**（实际累积故障率 vs 预测曲线，含置信带），展示预测可信度报告（CV、VaR区间、分布图）。
  4. **可信度与精度**：蒙特卡洛模拟给出未来总台次/总金额的分布、标准差、CV、VaR；提供模型拟合精度（R²、MAE等）。

## 二、Streamlit 界面设计要求
### 1. 页面布局
- 侧边栏：全局设置区（保修期、行驶里程参数、模拟次数、分段设置等）。
- 主区域分为三个部分：
  - **数据导入区**
  - **预测结果展示区**
  - **下载区**

### 2. 数据导入区详细设计
- **月度销量导入**：独立上传区域，接受CSV或Excel（列 `销售月份`、`销量`）。展示预览。
- **索赔数据导入模式切换**：单选按钮“单系统导入” / “多系统导入”。
  - **单系统导入**：两个上传按钮——“上传索赔台次”和“上传索赔金额”，每个接受一个Excel文件（单系统三角形）。导入后展示热力图。
  - **多系统导入**：
    - 显示9个系统折叠面板或标签页，每个系统独立包含两个上传按钮：“上传台次”和“上传金额”。
    - 系统列表：发动机系统、底盘系统、传动系统、转向系统、车身系统、车身内饰、车门天窗、电气系统、三电系统。
    - 未上传的系统被忽略，每个系统导入后可展开查看原始三角形。
- **数据自动校验**：
  - 校验三角形行列与销量月份对齐。
  - 自动检测增量/累积并转换（提示用户）。
  - 缺失值处理提醒。

### 3. 预测设置区（侧边栏）
- **保修期设定**：
  - 保修期月数（默认36，必填）
  - 保修期里程限制（公里，选填，留空则仅按时间）
- **每月行驶里程输入**：
  - 固定值（公里/月），适用于所有车辆。
  - 或上传CSV（`销售月份`、`月均行驶里程`），可为不同批次设置不同值。
  - 若未提供，威布尔模型仅使用时间维度（纯时间模型）。
- **预测方法**：
  - 台次预测：极大似然威布尔 / 贝叶斯威布尔（PyMC）
  - **单次维修成本预测**：移动平均法 / 指数平滑法 / XGBoost回归 / 简单历史均值（可多选或提供默认推荐）
- 蒙特卡洛模拟次数（默认5000）
- **威布尔分段设置**：
  - 手动分段：输入分段点列表（如 `[12, 60]`）
  - 自适应智能分段：系统自动基于曲率变化选择分段点
  - 显示分段结果，允许微调

### 4. 结果展示区设计
#### （1）预测三角形与故障率曲线
- 每个系统提供选项卡，展示“索赔台次”和“索赔金额”的完整三角形（历史+预测）。预测值单元格以**浅黄色底色**高亮。
- **故障率曲线图**：
  - 横轴：车龄（月）或里程；纵轴：累积故障率。
  - 绘制各销售批次的实际累积故障率散点，叠加威布尔拟合曲线。
  - 若进行蒙特卡洛模拟，绘制90%置信带（阴影区域），展示预测可信度。
  - 图表下方显示拟合优度（R²、MAPE）。
- **单次维修成本趋势图**：
  - 横轴：车龄（月）；纵轴：单次维修成本（金额/台次）。
  - 展示历史各月的单次维修成本散点，以及预测模型输出的未来单次成本曲线（带置信区间）。

#### （2）按销售批次的汇总指标
- 表格列出每个**销售月份**（原点期）的以下指标：
  - 销量
  - 保修期内**累积故障率** = 该批预测总台次 / 销量
  - 保修期内**单台费用** = 该批预测总金额 / 销量
- 并提供折线图展示累积故障率随销售月份的变化趋势。

#### （3）跨批次月度汇总
- **月度平均故障率**（某月龄）：所有批次在该月龄的预测台次总和 / 在保车辆总数。
- **月度单次维修成本**（某月龄）：所有批次在该月龄的预测金额总和 / 预测台次总和。
- **月度单台费用**（某月龄）：所有批次在该月龄的预测金额总和 / 在保车辆总数。

#### （4）预测可信度报告
- 未来总台次和总金额的期望值、标准差、变异系数（CV）、90% VaR、95% VaR。
- 蒙特卡洛模拟分布直方图（含VaR标注线）。
- 若用户上传了验证数据（真实未来值），展示MAE、MAPE等精度指标；否则提示“无验证数据”。

### 5. 下载区
- 下载填充三角形Excel（四个Sheet：台次、金额、单台费用、故障率），预测单元格保留浅黄色底色。
- 下载汇总报告CSV（含批次累积故障率与单台费用）。

## 三、数据格式详细规范
### 1. 月度销量文件
- CSV，两列：`销售月份`（YYYY-MM）、`销量`（整数）。

### 2. 索赔三角形文件（金额/台次通用）
- Excel，每个系统为一个Sheet。
- 行：`销售月份`（与销量对应）；列：发展期 MIS0,MIS1,MIS2,…（整数），数值为增量索赔金额（或台次）。
- 系统自动检测增量/累积并提示。

### 3. 月均行驶里程文件（可选）
- CSV，两列：`销售月份`（YYYY-MM）、`月均行驶里程`（公里/月）。

## 四、预测方法与算法要求

### 1. 索赔台次预测：双变量威布尔竞争风险模型（时间+里程）
- 若用户提供行驶里程信息，则采用**时间-里程双变量竞争风险威布尔**；否则退化为纯时间威布尔。
- 生存函数：\( S(t,m) = \exp\left[-\left(\frac{t}{\eta_t}\right)^{\beta_t} - \left(\frac{m}{\eta_m}\right)^{\beta_m}\right] \)。
- **尺度参数共享**：η_t 和 η_m 可全局共享（或分段共享）；**形状参数 β 分段独立**，保证曲线在分段点连续。
- **自适应分段**：基于累积故障率曲线的曲率变化自动选择最优分段点，支持手动覆盖。
- **蒙特卡洛模拟**：采样参数协方差矩阵或贝叶斯后验，计算预测台次分布。

### 2. 单次维修成本预测
- **定义**：对于每个发展期（车龄月），单次维修成本 = 该月龄的总索赔金额 / 总索赔台次（全局聚合，或分系统、分销售批次加权）。
- **预测模型**（用户可选）：
  - **简单历史均值**：直接用历史各月龄的平均单次成本作为未来预测值。
  - **移动平均/指数平滑**：对单次成本序列进行平滑预测，减少噪声。
  - **XGBoost/LightGBM 回归**：构建特征（车龄、车龄平方、系统编码、里程段等），以历史单次成本为标签训练模型，预测未来车龄下的单次成本。模型可捕捉非线性趋势和系统差异。
  - 支持残差 Bootstrap 获取预测区间。
- **模型共享策略**：单次成本模型可跨销售月份共用，但可按系统独立训练，以捕捉不同系统的维修成本差异。
- 输出未来各月的预测单次维修成本，并生成预测区间（蒙特卡洛模拟）。

### 3. 索赔金额预测
-第一方法采用链梯法或LightGBM发展因子填充金额三角形
- 第二种方案采用未来某月某系统的索赔金额 = 该月该系统的预测索赔台次 × 该月龄的预测单次维修成本。
- 蒙特卡洛模拟时，每次迭代同时从台次分布和单次成本分布抽样，相乘得到金额分布，确保相关性被正确反映。

### 4. 在保车辆数计算
- 按时间：第 j 月仍在保 = 销量（j ≤ 保修月数）。
- 按里程：若设里程限制，根据月均里程计算累积里程，超限则退出。
- 若缺少里程数据，仅按时间。

### 5. 指标定义
- **批次累积故障率** = 该批在保修期内的总预测台次 / 销量
- **批次单台费用** = 该批在保修期内的总预测金额 / 销量
- **月度平均故障率（某月龄）** = 所有批次在该月龄的预测台次之和 / 该月龄在保车辆总数
- **月度单次维修成本（某月龄）** = 所有批次在该月龄的预测金额之和 / 预测台次之和（等价于预测的单次成本模型输出）
